# Bloom Spire — 花灯りの塔

かわいい3人の冒険者と、花灯りの塔を目指すデッキ構築ローグライク。

![Bloom Spireの戦闘画面](preview.jpg)

## すぐに遊ぶ

ZIPを展開し、`index.html` をChromeまたはEdgeで開いてください。インストール、アカウント、APIキーは不要です。

別途お渡ししている **BloomSpire-Play.html** は、画像・音楽・プログラムをすべて含む1ファイル版です。こちらもダウンロードしてブラウザーで開くだけで遊べます。

## 内容

- **3人の冒険者**：リリィ（開花）、ルーナ（氷結）、ミエル（毒）
- **3章・全36階**：こもれびの森 → 月鏡の庭 → 星咲きの塔
- **57種類のプレイ用カード**＋呪い・状態異常2種類。カードごとの強化版
- **22種類のレリック**、4種類のポーション
- **18種類の敵**：通常敵、エリート、章ボス3体。ボスはHP半分で覚醒
- 分岐マップ、3択のカード報酬、ショップ、削除サービス、休憩、宝箱、8種類のイベント
- 難易度「おさんぽ」「冒険」「月夜の試練」
- シード値で再現できる冒険
- 自動保存、記録の書き出し・読み込み、直近20回の冒険記録、カード図鑑
- PCのクリック・ドラッグ・キーボード操作とスマートフォンのタップ操作
- オリジナルの環境BGM・効果音、アニメーションの切り替え

## 遊び方

1. 「新しい冒険」でキャラクターと難易度を選びます。はじめてなら「リリィ」「おさんぽ」がおすすめです。
2. マップの光っている場所を選びます。線でつながる次の階へ進めます。
3. 戦闘では、攻撃カードを選択してから敵を選択します。防御・自己強化はカードをクリックするだけで使用できます。
4. 左下のエナジー内でカードを使い、「ターン終了」で敵の行動へ。敵の頭上には次の行動が表示されています。
5. 勝利後は3枚から1枚を選んでデッキに追加。追加せずに進むこともできます。
6. 休憩ではHP回復かカード強化、ショップではカード・レリック購入や不要カードの削除ができます。
7. 各章12階のボスを倒し、最後の塔を攻略しましょう。

### キー操作

| 操作 | キー |
| --- | --- |
| 手札を選択 | 1〜9 |
| 対象選択をキャンセル | Esc |
| 敵が1体のとき、選択カードで攻撃 | Enter |
| ターン終了 | Space |
| デッキ | D |
| マップ | M |

スマホでは手札を横にスワイプできます。PCでは攻撃カードを敵へドラッグして使うこともできます。

### 主なルール

- 毎ターン、基本3エナジーが回復して5枚を引きます。手札の上限は10枚です。
- ブロックはダメージを防ぎ、次の自分のターン開始時に消えます。「とこしえの庭」で保持できます。
- 開花・筋力はアタックの各ヒットのダメージを増やします。敏捷性はカードで得るブロックを増やします。
- 氷結は敵の各ヒットの攻撃力を減らし、敵の行動後に1減ります。
- 毒は敵の行動前にブロックを無視してダメージを与え、その後1減ります。
- 脱力は攻撃ダメージを25%減らし、無防備は受ける攻撃ダメージを50%増やします。
- 廃棄されたカードは、その戦闘では戻りません。次の戦闘では通常どおりデッキに戻ります。
- パワーの効果はその戦闘中続き、使用カードは廃棄されます。
- ポーションは3個まで所持できます。回復薬は戦闘外でも使用できます。
- 章ボスの後にレリックを選び、次の章へ進むと最大HPの40%を回復します。

## GitHub Pagesで公開する

ビルド不要の静的ゲームです。画像などの参照は相対パスなので、リポジトリ名が何でも動作します。

1. GitHubで公開用リポジトリを作成します。
2. このZIPを展開し、**`index.html`、`style.css`、`app.js`、`engine.js`、`data.js`、`assets`フォルダ**を、リポジトリ直下にアップロードします。ほかの同梱ファイルも一緒に置いて構いません。
3. リポジトリの **Settings → Pages** を開きます。
4. **Source：Deploy from a branch** を選択します。
5. **Branch：main**、**Folder：/(root)** を選んで **Save**。
6. 公開が完了すると、同じPages画面にゲームのURLが表示されます。

ZIPファイルそのものをアップロードするだけでは遊べません。**中身を展開してアップロード**してください。`assets`の名前や階層を変えないでください。

公開設定の確認元：[GitHub公式：公開元を設定する](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## セーブ

冒険・設定・戦績は端末のブラウザー内に保存されます。サーバーは使用しません。各操作後に保存され、戦闘途中から再開できます。

設定の「冒険の記録を書き出す」でJSONファイルを保存できます。別の端末では「記録を読み込む」から引き継いでください。ブラウザーのデータ削除、プライベートモード、ファイルを開く方法の変更などで保存先が変わる場合があります。

1ファイル版とGitHub Pages版で保存先が異なる場合は、記録を書き出して移行してください。

## 改造する

| ファイル | 役割 |
| --- | --- |
| `index.html` | 起動ページ |
| `style.css` | 画面、レスポンシブ対応、演出 |
| `data.js` | カード・敵・レリック・イベントの定義 |
| `engine.js` | 戦闘、マップ生成、ショップ、報酬、保存データ |
| `app.js` | 画面表示、操作、音、ローカル保存 |
| `assets/` | 背景・キャラクター・カードイラスト |
| `tests/engine.test.cjs` | ゲーム進行・戦闘ルールの自動テスト |
| `server.cjs` | 任意で使うローカル確認用サーバー |
| `tools/build-standalone.py` | 単体HTML版を作成するスクリプト |

Node.jsがある場合、`npm test` でテスト、`npm run dev` でローカル確認用サーバーを起動できます。npmパッケージのインストールは不要です。

`python3 tools/build-standalone.py` で、同じ内容の1ファイル版を再生成できます。

ゲームの動作に外部CDN、フォント配信、API、解析スクリプトは使用していません。画像は同梱、音はWeb Audioで生成します。

## 確認範囲

戦闘・報酬・保存・3章の進行を自動テストで確認。ChromiumのPC画面と390px幅で、タイトル、マップ、手札、敵の選択、攻撃、防御、ターン終了、再開を確認しています。スマホ幅の確認はブラウザー内で行い、実機での操作感は未確認です。
